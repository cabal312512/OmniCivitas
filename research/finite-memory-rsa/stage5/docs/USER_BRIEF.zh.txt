# 1. 主攻完整 2-state stochastic temporal controller

Stage IV 已经形式化 edge-emitting stochastic temporal controller：

\[
p(a_1\cdots a_t)=\pi K_{a_1}\cdots K_{a_t}\mathbf 1.
\]

现在优先限制到最多两个 hidden states。

它是 one-bit operational memory 最自然、最强的 outcome-blind null，包含：

- IID orientation；
- stochastic switching；
- persistence；
- deterministic alternation；
- mixtures；
- action/state correlated transitions。

不要用有限网格代替完整 family。

目标是在现有 exact \(L=3,k=2\) periodic/open RSA 上，认证它能达到的 objective region 或至少足够精确的 support function。

---

# 2. 把问题写成真正的全局优化

继续使用三个核心目标：

\[
\theta,\qquad E|S|,\qquad E[A/N].
\]

对一组 scalarizations：

\[
J_{\mu,\nu}
=
E\theta-\mu E|S|-\nu E[A/N]
\]

计算：

\[
J^*_{\mu,\nu}
=
\sup_{\text{all proper 2-state stochastic temporal controllers}}
J_{\mu,\nu}.
\]

要求的是 **certified global bound**，不是局部 optimizer 的最好结果。

优先尝试适合当前 rational exact solver 的方法：

- interval branch-and-bound；
- rational subdivision；
- Bernstein polynomial/rational bounds；
- exact boundary decomposition；
- KKT/algebraic candidate enumeration；
- independent numerical optimizer 只用于找 lower bound，不作为认证。

如果一种方法行不通，可以组合方法。

关键是最终每个 support direction 都有：

\[
\text{certified lower bound}
\le J^*
\le
\text{certified upper bound}.
\]

尽量把 gap 压到能作科学判断的程度。

# 3. 先解决 one-bit feedback，不追求一次封死 4-state

Stage I–IV 已经完整知道所有 deterministic one-bit feedback classes。

把它们在 exact tiny systems 上的目标点，与完整 two-state stochastic temporal region 比较。

真正想得到的是以下二选一之一。

### Positive capability result

找到 feedback controller \(F\)，以及一个 support direction，使：

\[
J(F)>J^*_{\rm temporal}
\]

并且严格超过 certified upper bound。

这将证明：

> **在相同 one-bit operational-memory budget 下，outcome feedback 能实现任何 stochastic outcome-blind temporal controller 都无法达到的平均性能 trade-off。**

这是目前最想要的严格正结果。

### Negative capability result

如果可以证明全部 one-bit feedback objective points 都包含在完整 stochastic temporal attainable region / convex hull 中，则得到 scoped negative theorem：

> 在该 tiny geometry 和这些目标下，一位 outcome feedback 不扩大平均 objective region。

如果只能证明：

feedback point 没有越过 outer supports，

不能写成 inclusion。

保持区别。

# 4. 利用“所有 stochastic temporal laws 都是 word-law mixtures”

Outcome-blind temporal controller 在运行前产生一个与 adsorption outcomes 独立的 orientation process。

因此对于线性期望目标，随机 temporal law 可以视为 deterministic orientation-word laws 的混合。

利用这个结构。

特别研究：

\[
\sup_{\text{stochastic temporal word laws}}J
\]

是否等于：

\[
\sup_{\text{deterministic infinite orientation words}}J.
\]

若成立，正式证明。

这会提供一个甚至比 two-state null 更强的 comparator。

Stage IV 已经有 deterministic-prefix outer supports。现在尝试使用：

- exact prefix propagation；
- adaptive branch-and-bound；
- progressively strengthened suffix bounds；
- explicit lower-bound schedules；

让某些关键 support directions 的：

upper bound − lower bound

真正闭合。

如果能对 **unlimited-memory temporal word laws** 得到 exact support，那么任何 feedback point 越过它都会是极强结果。

# 5. 不需要画完整漂亮曲面，优先做 separation certificates

不要为了“完整 frontier 图”陷入无穷计算。

从现有 exact feedback points 出发，为最有希望形成 gap 的点寻找 separating hyperplane：

\[
J_{\mu,\nu}.
\]

然后集中计算对应 temporal support。

目标是得到少量但非常硬的结论：

- certified strict gap；
- certified equality；
- 或 certified unresolved interval。

十个严谨 support certificates 比一万个 stochastic 参数散点更有价值。

# 6. properness / liveness 必须保持一致

不要通过改变 admissibility 得到漂亮结果。

分别明确：

- universal liveness；
- fixed-geometry properness。

主要 capability comparison 使用预先声明的一种标准，并对双方一致。

如果某个 temporal optimum：

- 在 periodic \(3\times3\) proper，
- 但不是 universally live，

只能在对应 scoped theorem 中使用。

不要混写。

# 7. Operational-memory 公平性

对于每个参与最终比较的 feedback controller，使用 Stage IV 已经证明的 randomized operational-memory lower bound。

如果它严格需要两 states：

## 以最后一条要求为准

用户否定上一版，要求白色、通透、清亮、统一的科技视觉，删除尴尬文案并密集增加动画。随后强调张牙舞爪、东西多；又澄清 Logo 只是安静扉页，进入主页之后才乱。最后明确上一版保留不启用。

当前扉页只有原创银色 OCV 标志、OMNICIVITAS 文字 Logo、克制的轨道/粒子与进入动作。点击 Logo 或向下进入，导航、分叉光丝、密集粒子、浮动玻璃仪表、碎片、立体薄片、波形、横向图形集合和阵列再展开。原来的段子、口号、梗图、厨房/停机/收据表单与 iframe 不在当前首页。

上一版完整构建页面/素材快照和 Next 页面源码保存在 `historical/front_old`，旧功能源码/样式还在 apps 原目录，不挂载。原来的 `/borrowed` 回到新首页光场区；四条旧走廊回扉页；当前镜像 `/memes/`、旧 Angular 静态小窗和裸页 CSS 返回 404。此前递归删除被自动审批拒绝，未执行；用户已改为保留，不再删除。历史快照未启动容器，且被 .dockerignore 排除，不带入当前运行镜像。

## 实际动画与交互

- 原生 WebGL vertex/fragment shaders：环形、球体、流线、阵列连续混合，点击按钮真正改变几何；指针影响三维角度和局部排斥，点击激发衰减扩张。
- 向四周伸展的动态分叉曲线、星点、细线场；透明 SVG 仪表、交错轨道、CSS 3D 碎玻璃/叠层薄片/浮动阵列分层运行。
- Logo 金属渐变/阴影/高光与进入动画、光标附近照明、视差、3D tilt、波形描线、交错漂浮、横向图形集、滚动形态过渡。
- 界面仅保留 Logo、极少数数字和图标；控件有可访问名称、焦点样式，导航与图形选择可用键盘完成。扉页隐藏导航为 inert，避免键盘进入看不见的链接。
- reduced-motion 下停止动画、单帧更新几何；WebGL 不可用或 context lost 时提供 CSS 替身，进入/返回路径仍正常。

桌面完整场景 11,000 点/44,700 段线，小屏 5,500 点/15,080 段线；安静扉页实际只画 1,100 点/2,880 段轨道。画布最长边上限 1600，小屏 800；两次 GPU draw，单 RAF 每秒最多约 30 次。隐藏页面暂停，离开回收 buffer/program/事件，无动态增加无限节点。形态过渡与指针阻尼按经过时间推进，避免低帧率拉长动画。

**30 是上限，不是保证帧率。** 本机 headless 完整场景一次 750ms 观察到 7 帧，软件渲染性能低于该上限；真实硬件加速浏览器峰值没有作保证。无新增三方依赖。

# Ordinary-page window additions

User-authorized maintenance after website Phase 8, 2026-10-04. This does not start Phase 9. The research interface is protected; scientific work remains paused after Stage V.

The existing windows, media, visual effects and tool implementations remain. New straight rectangular fragments are distributed among ordinary pages. The screenshot references informed incomplete borders, clipped selection fields, overflowing controls and blank panes. No new external package or copied third-party effect was added.

## File map

- `config/apps/portal/src/q7/1.astro`: twenty distinct structures and deterministic per-address selection.
- `config/apps/portal/src/q7/0.css`: all new styling is namespaced under `n3`; the bare form's intended theme has a stranded, unreachable screen breakpoint.
- `config/apps/portal/src/q7/a.mjs`: one animation scheduler per page, bounded displacement, pointer/keyboard drag, close, counter and toolbar interactions. It pauses on hidden documents and the calm cover, respects reduced motion, and disposes on page replacement. No network submission, storage or accumulating DOM objects.
- `docs/window-additions-map.json`: every actual generated route for each design, collected from built HTML.
- `tests/browser/windows.spec.mjs`, `tests/windows.playwright.config.mjs`: four focused browser checks; artifacts remain under the local dependency root.

There are six additions per mounted page. The home cover hides them; they appear after entering the existing home content. Maze, tools, lab, portals, incidents, legal, media, search, status, error and old corridor templates mount the layer. Research, fictional identity screens and the standalone 3D game do not mount it. Fixed exit controls retain their existing priority. Not every decorative fragment has a toolbar; background fragments cannot intercept input.

## Verification boundary

217 HTML pages built; 177 contain additions and all twenty designs occur. Thirty research routes contain none. Four focused browser checks passed in a single run, including actual navigation and resolved links, calm-cover exclusion, mouse drag/close, checkbox/counter, autonomous movement and reduced-motion behavior. Two ordinary-page screenshots were visually inspected. The 23 protected research interface/music files match their pre-edit SHA-256 values. The three original requirement ledgers retain their original hashes.

Deployment and core status are recorded in `window-additions-acceptance.json`. This maintenance does not claim a full old-site regression, rerun any scientific experiment, generate a PDF, or perform the pending public-release portability audit.

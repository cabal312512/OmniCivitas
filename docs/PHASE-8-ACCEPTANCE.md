## 范围与限制

- 只接受第八阶段；第九阶段未授权。
- 六项旧条文由用户最新逃跑次数、手机越界及不设停止动画按钮要求覆盖，原文仍保留。
- CSS 动画时间轴通过真实浏览器样式引擎 seek 核对；标题/favicon 用模拟时钟，四秒假死及十秒成就等待使用真实时间。
- 生命周期 persisted 事件是合成检查，不宣称实际 BFCache 或系统挂起。
- 手机可越界；提示关闭的实际鼠标悬停行为在桌面验证，手机保留原生键盘关闭。
- 文明指数使用任意精度十进制 BigInt，无人为数值上限；存储容量仍受浏览器限制，写拒绝退内存。
- 假状态、伪版本和索引均为娱乐展示；客服本地自动回复，没有实际人工服务。
- 历史源码、Biome/Kubernetes/Maven/Terraform 按停用角色审查，没有安装或运行这些历史工具链。
- 额外 Hono 128 MiB 仅按需真实验证配置优先级，随后关闭；全部其他可选服务本阶段不宣称重新实测。
- 七个直接构建工具许可及原十份许可核对；传递依赖、用户素材再分发、干净 clone 和跨平台公开发布审计仍待第九阶段。
- Docker/WSL 内存为浏览器检查之后的工作集采样，不保证长期峰值。

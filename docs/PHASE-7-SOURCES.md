# 第七阶段实现边界

本阶段为 B071–122、B124–140 共 69 条。只接入本地基础小游戏、奇葩工具与固定模板生成器；历史界面和所有原文保留。第八阶段未授权。

本轮没有为了小游戏安装新框架。棋盘、移动/合并、基础碰撞和翻牌用短小独立纯函数；Canvas、SVG、CSS、performance.now 和 Web Crypto 使用浏览器原生接口。游戏不接排行榜、真实账户或多人服务。已有 Three.js/GSAP 光场仍保留真实挂载，其许可继续保留。

输入只在当前工具窗口里处理。鼠标/滚轮测量从本站页面入口启动，仅保留 CSS 像素匿名累计与计数，跨本标签页路由保存 ocv.mileage.v1；不保存轨迹坐标、按键或表单输入。纳米换算为 1 px = 1,000,000 nm 的演示规定，不是设备物理距离。存储拒绝时退回内存。

轨迹公证只使用用户主动在当前工作台画出的点，点数有上限；在本地生成 SVG 原字节，离开清理。Cookie 工具只创建/评估几项明确命名的本站演示 Cookie，不枚举其他 Cookie，不做浏览器隐私分析。

所有动态工作台需支持取消、隐藏暂停、离开清理与系统减少动画。等待工具实际计满 15 秒，加载鉴赏中永久动画只作不阻塞的展示。生成器使用预设文字模板，无大模型调用。

运行证据、边界与最终条目数以 PHASE-7-ACCEPTANCE.md 和 phase-7-acceptance.json 为准。第九阶段公开可移植性、干净 clone、多平台及全部素材/依赖许可审计仍待办。

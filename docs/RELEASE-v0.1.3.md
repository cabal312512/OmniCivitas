# OmniCivitas v0.1.3

This release extends exploration, audio tools, profiles and collections while preserving the frozen research record.

- Expanded 3D world with distinct cities, towns, street details, wind turbines, moving entities and varied combat. City guardians unlock flight; checkpoints, achievements and medals persist. The windowed entrance includes controls help and a confirmed progress reset.
- Music composition, recorded-audio processing, collectible characters, editable profiles, avatars and achievement collections. Private contact inputs are not retained as real account data.
- Bounded background receipts and on-demand backend service batches, with database persistence when core infrastructure is available. Optional infrastructure remains separate from ordinary frontend development.
- Source publication excludes AI briefs, handoffs, internal plans, decision and acceptance records, compiled paper PDFs, runtime state, credentials and dependency caches. Scientific manuscripts, data, figures, original manifests and required license notices remain included; excluded sealed files are declared in the publication policy.

Start with [English deployment instructions](DEPLOY.en.md), or [中文部署说明](DEPLOY.zh-CN.md). Run `pnpm install --frozen-lockfile` and `pnpm dev` for local development. Docker starts core by default; select optional services in bounded batches.

The source archive is the tracked source tree, not a prebuilt application. Review the deployment prerequisites and environment example before building. Original code is MIT, copyright 2026 cabal312512; third-party code and media retain their respective terms.

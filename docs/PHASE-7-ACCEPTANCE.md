## 范围和限制

- Only phase 7 is accepted. Phase 8 is not authorized.
- Games are local basic versions, not multiplayer/leaderboards/general physics.
- Anonymous mouse/wheel totals use CSS pixels and a fictional nm conversion; session write failure falls back to memory. No input or coordinate history is retained.
- Only explicitly named site demonstration cookies are created/evaluated; other cookies are not enumerated.
- Trajectory SVG is a local parody certificate, not a legal instrument.
- Hidden/persisted lifecycle checks use simulated browser events where stated; they are not a real BFCache/OS-suspend benchmark.
- Deliberate overlap and mobile cropping remain; native keyboard, focus and window-raise provide completion.
- Only six core services are exercised; optional services are not claimed rerun. Docker/WSL working set is a post-test sample, not a long-term peak guarantee.
- Phase 9 portability, clean clone, multi-platform and full license audit remain pending.

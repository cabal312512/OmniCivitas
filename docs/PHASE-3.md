# 第三阶段执行范围

用户已于 2026-10-02 授权。77 条主要阶段要求，另补 A042 浏览器 Yup；71 项阶段技术逐项取得真实用途与运行证据。验收后停止，不提前实现三个门户、身份系统及工具全集。

1. Astro 的 Vue/Svelte/Solid 小岛，Lit/Alpine/htmx/jQuery，浏览器数据库与记录重建。
2. Next/React 部门页面及 API 中转，Redux/Zustand/MobX/Jotai/XState/RxJS/TanStack、两种表单、混合 UI/CSS 与日期链。
3. Angular 独立 CLI 构建的小窗，Signals/Reactive Forms，受限同源 postMessage 两布尔协议。
4. 默认 core 衔接真实 Next 页面；Angular 只提供静态包。Docker/宿主重型构建串行，保持每日 WSL 9 GiB，可选基础设施只按需验证。
5. 浏览器实际验证每项框架/库的可操作结果、刷新/关闭恢复、跨标签消息、Worker、清除存储后重建、JSON 下载、错误释放、核心/可选服务边界与真实 Yup→Zod→Java→SQLite。
6. 78 条逐项证据（含 A042）与 71 项用途核对，源码 hash 不变；公开部署约束持续检查，第九阶段的独立审计不提前冒充完成。

本阶段新增应用配置与普通构建/启动入口不得写入机器盘符。实际本机依赖与缓存通过独立 PowerShell 辅助联接到用户指定目录。

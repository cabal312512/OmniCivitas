## 动效实现与预算

window.__ocvOptics 是实际诊断数据：renderer、frames、点/线数量、activeGeometry、scroll、morph、pointer、reduced、suspended。四种 WebGL 形态为环形/球体/流线/阵列，真正由 vertex shader 混合几何；不是切换图片。指针调整空间角度与局部排斥，点击产生衰减扩张。动态分叉曲线向四周伸展；SVG/CSS 的卫星仪表、碎玻璃、轨道、薄片、波形、浮动阵列与之分层。

扉页实际仅绘制 1100 点、2880 段轻轨道；进入后桌面 11000 点、44700 段线，小屏 5500 点、15080 段线；画布最长边最多 1600（小屏 800）；单个 RAF 约 30 FPS 上限，两次 GPU draw；不是帧率保证，headless 完整场景实际帧率较低，详见修订报告。页面隐藏时停止，恢复时重新唤醒；reduced-motion 单帧更新，控件/导航仍可用。pagehide 非缓存离开回收 buffers/program、撤事件；WebGL 无法使用或丢失时提供 CSS fallback。不要忘记 uniform/varying 的 VS/FS 精度一致，本轮曾修该 link 错误。

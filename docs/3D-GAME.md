# 3D 游戏

2026-10-03，用户授权的第八阶段追加维护。实际入口 /functions/3d-world/，游戏目录 /functions/games/、全部功能目录和万能搜索均可找到“3D游戏”。当前111工具、13分类、11游戏；原十个小游戏保持。默认960×600左右的小窗口，原生全屏；页面无可见文字、标题、菜单或数字，只显示图标、准星、生命条和收集点。

## 操作

| 操作 | 效果 |
| --- | --- |
| WASD、鼠标 | 第一人称移动/视角；眼高2.2米 |
| 点击画面 | 浏览器允许时锁定鼠标；拒绝时仍可右键拖动/方向键看四周 |
| Shift | 58米/秒疾跑；无体力条、无消耗或疲劳 |
| Space | 跳跃；不能在空中再次跳跃 |
| 左键、准星图标 | 能量射击；画面左键按住可连发 |
| E、光环图标 | 靠近光环后传送到下一地区 |
| Q、磁盘图标 | 仅在绿色休息区保存当前浏览器进度 |
| R、回转图标 | 恢复生命并回到已存档点；未存档回出生点 |
| F、右上图标 | 原生全屏/窗口切换 |
| Esc | 明确退出鼠标锁定和全屏 |
| 音量图标、左上箭头 | 静音、退出到游戏目录 |

高速移动按时间和距离自适应拆步，每步不超过0.24米，避免穿薄墙；斜向速度归一，保留滑墙、地形高度、桥面与边界。游戏声音是本轮原创Web Audio合成，手势后才启动，包含轻风、鸟鸣、脚步/涉水、射击与反馈。

## 世界与玩法

12×12公里、144平方公里，X/Z范围±6000米。近景最多25个512米块、64段细分；远距离传送先释放旧块再加载。近远景精确遮罩及真实索引洞共同避免粗糙地形穿出河面，也适用于SSAO深度图。地形、丘陵、连续河流、桥、三处住宅小镇及五种城市。

加66住宅，共243建筑。实际26长椅、8候车亭、100路灯、6长围栏、8玻璃井、2反射池、2柱廊、2泳池围墙、游乐场、球场、2步行桥、20芦苇组、河岸台阶、6踏石和5低墙。原树木代码保留，当前不生成树木。

原有巨球、圆环、碑、拱门、楼梯、巨大玻璃水母和四足景观保留。新增16种独特草原巨物/173实际Mesh，地面、低空、半埋、高空各4种，包含分段椭球、镜面巨板、空心透明框、断拱、双螺旋、斜盘、轨道、阶梯、珍珠柱、晶体、巨链、折叠结构等。6个探索光环追加在原传送链后，所有落点及到达位置可走。实体的实际边界/高度记录在world.stats.meadowArtifacts；浮空结构不占地面碰撞区，地面实体使用有限高度阻挡。

91个可射击实体、5种轮廓/行为：晶球、主动无人机、追击近战步行体、两层护盾哨兵、三发分散齐射水母。不同生命/护盾，受击或攻击时显示无文字血条；视线、地面、墙体、距离和冷却真实约束。48敌弹固定池；出生区安全。死亡变为掉落，靠近收集回血并计入八种发现，收集后有限时间重生。

五片城市另有40个无害NPC、5种外形：白珠步行体、玻璃服务车、浮动数据包、三足机器人、胶囊体。自主漫游/避墙/限制范围；2–4HP，可射击摧毁/收集，受伤也不反击。NPC计数独立，ID1000+不写入原发现存档，避免混入原敌人范围。

8处休息区持续回血并保护玩家。Q或磁盘图标保存到ocv.aero.checkpoint.v1，仅version/checkpoint/found/health/energy；旧energy字段为存档兼容，移动时固定1。恢复位置由已知休息区和实际地面计算，不保存任意坐标/输入/账户。损坏或未知版本回出生点；拒绝存储时退当前会话，刷新不会假装仍有持久存档。敌人/NPC临时战斗状态重新生成。

## 画面与来源

屋顶法线、原创草地/沥青/外墙/屋顶纹理、凹凸/粗糙度；PBR透射/环境反射/清漆玻璃；有明暗的原创云密度纹理、HDR太阳及辉光、真实2048阳光阴影、接触阴影、轻bloom和颗粒。河面为Fresnel、天空反射和太阳高光。是程序几何/材质的风格化游戏，不宣称照片级真实。

五张用户图片仅用于参考，没有复制为纹理。另研究[Dreamcore Pool](https://holly95.artstation.com/projects/5Wzmmg)与[Sunken Amphitheatre](https://dreamyrobot.artstation.com/projects/o0AAOk)的空间/清亮水面和反射构成，未复制图片、模型、材质、shader或游戏代码。新增几何/纹理/shader/声音原创；使用已有Three.js及随库后处理，无新包下载，原MIT归属与二十许可资源原字节保留。
